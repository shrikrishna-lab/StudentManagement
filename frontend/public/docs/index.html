Relational Design

Database Schema & Table Structure

Schema specifications for database: student_management

Column Name MySQL Data Type Constraints Architectural Purpose
id INT PRIMARY KEY AUTO_INCREMENT Internal surrogate primary key generated automatically by MySQL (1, 2, 3...).
roll_number INT UNIQUE NOT NULL Unique student roll number. Database-level safeguard against duplicates.
name VARCHAR(100) NOT NULL Student's full name. Variable-length string up to 100 characters.
email VARCHAR(100) NOT NULL Validated email address format for notifications.
phone VARCHAR(15) NOT NULL 10-digit mobile contact number stored with national prefix tolerance.
course VARCHAR(50) NOT NULL Department abbreviation (IT, CS, EXTC, MECH).
year INT NOT NULL Academic year of study (1 to 4).
division VARCHAR(10) NOT NULL Class cohort division letter (A, B, C).
percentage DECIMAL(5, 2) NOT NULL Exact academic percentage (e.g. 89.50) without floating-point rounding errors.
